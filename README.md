# assessment-ecommerce



Assignment: E-commerce Website Frontend
Technology: Angular (Frontend Only)

Develop a responsive e-commerce website with the following pages and functionalities:

Home Page: Create an attractive homepage with banners, product categories and featured products.

Registration Page: Build a user registration form with proper field validations.

Product Listing Page: Display products with images, names, prices and categories.

Product Details Page: Show complete product information when a user selects a product.

Add to Cart: Allow users to add products to their shopping cart.

Cart Functionality: Display added products and automatically update the cart count in the navbar whenever a product is added.
